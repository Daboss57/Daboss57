### PanGenome Insight Platform
A research-friendly bioinformatics platform for interpreting variation across linear and graph-based references. Built around FastAPI, TypeScript/React, Nextflow workflows, a Python CLI, plugin manifests, and provenance-aware analysis.

### VICEAI
An AI-control research overlay for the Vice ATC simulator. Includes observation/action schemas, action masks, behavior-cloning training tools, JSONL episode processing, and a Go bridge for simulator interaction.
